# 팬 매거진 리뉴얼

열려 있던 카카오톡의 매거진 시안 4장과 확정된 설명을 기준으로 한다. 대화의 개인 정보는 구현에 포함하지 않는다.

- 메인: 화면을 채우는 사진과 왼쪽 아래 ‘피치사이드 매거진’ 제목 → 검은 배경의 기존 3D 책 선반.
- 상세: 책을 선택하면 큰 표지 사진과 제목 → 흰 배경의 사진·본문. 본문 폭 700px, 큰 중간 사진, 기존 문장 카드 유지.
- 실제 인물 사진과 원고는 추후 교체하기로 했으므로 현재 예시 콘텐츠를 재사용한다.
- 기존 URL, 소개·Stories 콘텐츠, 기사 사이트 테마, 선반 조작을 유지한다. 소개·사진 마키·Stories는 선반 다음에 놓는다.
- React·CSS로 구현하며 의존성을 추가하지 않는다. 메인/상세가 표지 컴포넌트를 공유한다.
- 기존의 어두운 상세를 유지하는 안보다 대화에서 확정된 ‘메인 어둡게, 상세 밝게’를 우선한다. 전체 재작성보다 기존 선반과 본문 재배치가 범위에 맞는다.
- 디자인: 사진 중심의 편집형 매거진. 구성 변화 6, 모션 4, 밀도 3. 기존 폰트와 브랜드를 유지하되 표지 제목은 시안의 굵은 산세리프를 따른다.
- 모바일, 움직임 줄이기, 사진 실패 대체 화면, 뒤로 가기, 테마 복원을 확인한다.

- 메인 표지의 사진·제목은 스크롤보다 천천히 움직이고 선반 지면이 아래부터 덮는다. 움직임 줄이기 설정에서는 일반 스크롤을 유지한다.
- 상단 메뉴는 PITCHSIDE MAGAZINE과 Articles 두 링크 버튼으로 간소화한다.
